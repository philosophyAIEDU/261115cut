설치하기

보통 프로그램처럼 설치합니다. 따로 깔아야 할 것은 없습니다.

  1. 설치 파일 내려받기

    위의 「무료로 내려받기」를 누르면 SophiCut-Setup.exe가 다운로드 폴더에 저장됩니다.

    브라우저가 "일반적으로 다운로드되지 않는 파일"이라고 하면, 파일 옆 ⋯ → 유지 → 그래도 계속을 누르세요. 새로 나온 프로그램이라 뜨는 안내입니다.

  2. 설치 파일 실행하기

    다운로드 폴더에서 SophiCut-Setup.exe를 더블클릭하세요. 파란 창이 뜨면 이렇게 누릅니다.

    「Windows의 PC 보호」 창이 뜨면
    Windows의 PC 보호
    Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다…
    추가 정보 ← ① 이것을 누르고
    실행실행 안 함

    ② 새로 나타난 「실행」 버튼을 누릅니다.

  3. 설치 마법사 따라가기

    다음 → 설치 → 마침을 차례로 누르면 됩니다. 관리자 권한은 필요 없습니다.

    「바탕화면에 소피컷 아이콘 만들기」에 체크해 두면 다음부터 찾기 쉽습니다.

  4. 소피컷 실행

    바탕화면(또는 시작 메뉴)의 소피컷을 더블클릭하면, 인터넷 브라우저에 소피컷 화면이 열립니다. 브라우저에서 열리지만 내 컴퓨터 안에서만 동작합니다.

    처음 영상을 넣으면 받아쓰기 AI를 한 번 내려받느라 몇 분 걸립니다. 다음부터는 바로 시작됩니다.

3분 사용법

영상 넣기 → 원고 다듬기 → 완성본 만들기, 이것만 알면 됩니다.

1

영상 넣기

첫 화면에 영상 파일을 끌어다 놓으세요. AI가 말을 원고로 받아 적습니다.

2

지울 말 고르기

원고에서 단어를 마우스로 끌어 고르고 Delete. 한 번 더 누르면 되살아납니다.

3

한 번에 정리

다듬기 도구의 빈틈 정리와 추임새 지우기로 군더더기를 걷어 냅니다.

4

자막 꾸미기

자막 도구에서 굵기·색·테두리·배경을 바꾸거나 준비된 스타일을 고릅니다.

5

이미지·속도

이미지 도구로 사진을 얹고, 속도 도구로 지루한 부분을 빠르게 넘깁니다.

6

완성본 만들기

오른쪽 위 완성본 만들기에서 영상+자막, 영상만, 자막 파일(SRT), 원고(TXT)를 고릅니다.

Space 재생 · Ctrl+Z 되돌리기 · Enter 문단 나누기 · 더블클릭 글자 고치기

다 쓰고 나면 오른쪽 위 「종료」를 누르세요. 그냥 브라우저 탭을 닫아도 몇 분 뒤 저절로 꺼집니다. 작업은 자동 저장됩니다.

새 버전 받기

소피컷은 계속 좋아집니다. 업데이트는 두 가지 방법 중 편한 쪽으로 하세요.

✦ 소피컷이 알려 줄 때

새 버전이 나오면 소피컷 첫 화면 위쪽에 「새 버전이 나왔습니다」 알림이 뜹니다. 새 버전 받기를 눌러 받은 파일을 실행하면 끝입니다.

⬇ 이 사이트에서

언제든 이 페이지의 「무료로 내려받기」로 최신 설치 파일을 받아 실행하면 됩니다. 설치 방법은 처음과 같습니다.

업데이트해도 작업하던 프로젝트와 저장한 자막 스타일은 그대로 남습니다. 지우고 다시 설치할 필요 없이 덮어서 설치하면 됩니다.

도움말

막히는 부분이 있으면 여기부터 확인해 보세요.

컴퓨터 사양이 어느 정도 필요한가요?

Windows 10/11 64비트, 메모리 8GB 이상, 여유 공간 5GB 이상을 권장합니다. 인터넷은 설치하고 처음 받아쓰기 AI를 내려받을 때만 씁니다.

받아쓰기가 너무 느려요

NVIDIA 그래픽카드가 있다면 소피컷 첫 화면에 「GPU 가속 받기」가 보입니다. 한 번 받아 두면(약 1.3GB) 받아쓰기가 몇 배 빨라집니다.

그래픽카드가 없다면 영상을 넣기 전에 받아쓰기 AI를 「가벼움」으로 바꿔 보세요. 정확도는 조금 낮아지지만 훨씬 빠릅니다.

소피컷을 눌렀는데 화면이 안 열려요

브라우저 주소창에 http://127.0.0.1:7860을 입력해 보세요. 그래도 안 되면 컴퓨터를 다시 시작한 뒤 소피컷을 실행하세요.

완성본(영상 파일)은 어디에 저장되나요?

완성본이 나오면 「저장하기」로 원하는 곳에 받거나, 「폴더 열기」로 저장된 폴더를 바로 열 수 있습니다.

백신 프로그램이 설치 파일을 막아요

새로 나온 프로그램이라 일부 백신이 조심스럽게 막는 경우가 있습니다. 이 사이트나 공식 GitHub에서 받은 파일이 맞다면 백신의 「허용」 또는 「예외」에 추가해 주세요.

내 영상이 인터넷으로 전송되나요?

아니요. 받아쓰기를 포함한 모든 작업이 내 컴퓨터 안에서만 이루어집니다.

지우고 싶어요

설정 → 앱 → 설치된 앱에서 소피컷을 찾아 제거하세요. 작업하던 프로젝트까지 모두 지우려면 파일 탐색기 주소창에 %LOCALAPPDATA%\SophiCut을 입력해 열린 폴더를 지우면 됩니다.

Mac에서도 되나요?

지금은 Windows만 지원합니다. 개발에 익숙하다면 GitHub 저장소의 안내대로 소스에서 직접 실행할 수 있습니다.
