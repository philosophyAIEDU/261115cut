설치하기

쓰는 컴퓨터를 고르세요. 따로 깔아야 할 것은 없습니다.

  1. 설치 파일 내려받기

    Windows용 설치 파일 받기를 누르면 SophiCut-Setup.exe가 다운로드 폴더에 저장됩니다. (Windows 10 / 11)

    브라우저가 "일반적으로 다운로드되지 않는 파일"이라고 하면, 파일 옆 ⋯ → 유지 → 그래도 계속을 누르세요. 새로 나온 프로그램이라 뜨는 안내입니다.

  2. 설치 파일 실행하기

    다운로드 폴더에서 SophiCut-Setup.exe를 더블클릭하세요. 파란 창이 뜨면 이렇게 누릅니다.

    「Windows의 PC 보호」 창이 뜨면
    Windows의 PC 보호
    Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다…
    추가 정보 ← ① 이것을 누르고
    실행실행 안 함

    ② 새로 나타난 「실행」 버튼을 누릅니다.

  3. 설치 마법사 따라가기

    다음 → 설치 → 마침을 차례로 누르면 됩니다. 관리자 권한은 필요 없습니다.

    「바탕화면에 소피컷 아이콘 만들기」에 체크해 두면 다음부터 찾기 쉽습니다.

  4. 소피컷 실행

    바탕화면(또는 시작 메뉴)의 소피컷을 더블클릭하면, 인터넷 브라우저에 소피컷 화면이 열립니다. 브라우저에서 열리지만 내 컴퓨터 안에서만 동작합니다.

    처음 영상을 넣으면 받아쓰기 AI를 한 번 내려받느라 몇 분 걸립니다. 다음부터는 바로 시작됩니다.

  1. 내 Mac에 맞는 파일 내려받기

    Mac은 칩 종류에 따라 파일이 다릅니다. 화면 왼쪽 위 사과 메뉴 → 이 Mac에 관하여를 눌러 확인하세요.

    「칩: Apple M1 / M2 / M3 / M4 …」라고 나오면
    Apple 칩용 받기
    「프로세서: … Intel …」이라고 나오면
    Intel용 받기

    2020년 말 이후에 산 Mac은 대부분 Apple 칩입니다.

  2. 응용 프로그램 폴더로 옮기기

    다운로드 폴더에서 받은 .dmg 파일을 더블클릭하면 창이 열립니다. SophiCut 아이콘을 옆의 Applications(응용 프로그램) 폴더 위로 끌어다 놓으세요.

    SophiCut
    →
    A
    Applications

    다 옮겼으면 dmg 창은 닫아도 됩니다.

  3. 처음 한 번만: 「그래도 열기」

    응용 프로그램 폴더에서 SophiCut을 더블클릭하세요. 앱스토어 밖에서 받은 앱이라 처음에는 Mac이 이렇게 막습니다.

    "SophiCut"이(가) 열리지 않음
    Apple은 'SophiCut'에 Mac을 손상시키거나 개인정보를 침해할 수 있는 악성 코드가 없음을 확인할 수 없습니다.
    완료휴지통으로 이동

    ① 「완료」를 누릅니다. (휴지통으로 이동은 누르지 마세요)

    • ② 사과 메뉴 → 시스템 설정 → 개인정보 보호 및 보안을 엽니다.
    • ③ 아래로 내리면 "SophiCut"이(가) 차단되었습니다 옆에 「그래도 열기」가 있습니다. 누르고 Mac 암호를 입력하세요.
    • ④ 다시 뜨는 창에서 「그래도 열기」를 누르면 소피컷이 열립니다.
    조금 오래된 macOS(14 이전)라면: SophiCut 아이콘을 control 키를 누른 채 클릭 → 열기 → 열기를 누르면 됩니다. 한 번 열고 나면 다음부터는 그냥 더블클릭으로 열립니다.

  4. 소피컷 실행

    인터넷 브라우저(Safari, Chrome 등)에 소피컷 화면이 열립니다. 소피컷은 Dock에 아이콘 없이 뒤에서 조용히 동작합니다. 다 쓰면 화면 오른쪽 위 「종료」를 누르세요.

    처음 영상을 넣으면 받아쓰기 AI를 한 번 내려받느라 몇 분 걸립니다. Mac에서는 그래픽카드 가속 없이 받아쓰므로, 긴 영상이 느리면 받아쓰기 AI를 「가벼움」으로 바꿔 보세요.

3분 사용법

영상 넣기 → 원고 다듬기 → 완성본 만들기, 이것만 알면 됩니다.

1

영상 넣기

첫 화면에 영상 파일을 끌어다 놓으세요. AI가 말을 원고로 받아 적습니다.

2

지울 말 고르기

원고에서 단어를 마우스로 끌어 고르고 Delete(Mac은 delete). 한 번 더 누르면 되살아납니다.

3

한 번에 정리

다듬기 도구의 빈틈 정리와 추임새 지우기로 군더더기를 걷어 냅니다.

4

자막 꾸미기

자막 도구에서 굵기·색·테두리·배경을 바꾸거나 준비된 스타일을 고릅니다.

5

이미지·속도

이미지 도구로 사진을 얹고, 속도 도구로 지루한 부분을 빠르게 넘깁니다.

6

완성본 만들기

오른쪽 위 완성본 만들기에서 영상+자막, 영상만, 자막 파일(SRT), 원고(TXT)를 고릅니다.

Space 재생 · Ctrl(Mac은 ⌘)+Z 되돌리기 · Enter 문단 나누기 · 더블클릭 글자 고치기

다 쓰고 나면 오른쪽 위 「종료」를 누르세요. 그냥 브라우저 탭을 닫아도 몇 분 뒤 저절로 꺼집니다. 작업은 자동 저장됩니다.

새 버전 받기

새 버전이 나오면 소피컷 첫 화면 위쪽에 「새 버전이 나왔습니다」 알림이 뜹니다. 새 버전 받기를 누르면 내 컴퓨터에 맞는 파일이 내려받아집니다. 이 페이지에서 받아도 똑같습니다.

Windows

받은 SophiCut-Setup.exe를 실행해 처음처럼 설치하면 덮어쓰면서 업데이트됩니다.

Mac

소피컷을 종료한 뒤, 새 dmg를 열어 SophiCut을 Applications로 다시 끌어 놓고 「대치」를 누르세요. 처음 열 때 「그래도 열기」를 한 번 더 해야 할 수 있습니다.

업데이트해도 작업하던 프로젝트와 저장한 자막 스타일은 그대로 남습니다.

도움말

막히는 부분이 있으면 여기부터 확인해 보세요.

컴퓨터 사양이 어느 정도 필요한가요?

Windows 10/11 64비트, 또는 macOS 13(Ventura) 이상을 권장합니다. 메모리 8GB 이상, 여유 공간 5GB 이상이면 충분합니다.

인터넷은 설치할 때와 처음 받아쓰기 AI를 내려받을 때만 씁니다.

받아쓰기가 너무 느려요

Windows + NVIDIA 그래픽카드라면 소피컷 첫 화면에 「GPU 가속 받기」가 보입니다. 한 번 받아 두면(약 1.3GB) 받아쓰기가 몇 배 빨라집니다.

그 밖의 컴퓨터(Mac 포함)는 영상을 넣기 전에 받아쓰기 AI를 「가벼움」으로 바꿔 보세요. 정확도는 조금 낮아지지만 훨씬 빠릅니다.

소피컷을 눌렀는데 화면이 안 열려요

브라우저 주소창에 http://127.0.0.1:7860을 입력해 보세요.

Mac에서 방금 소피컷을 닫았다면 1~2분 기다렸다가 다시 실행하세요. 그래도 안 되면 컴퓨터를 다시 시작한 뒤 실행해 주세요.

Mac에서 "손상되었기 때문에 열 수 없습니다"라고 나와요

내려받는 중에 파일이 깨졌을 수 있으니 먼저 이 페이지에서 다시 받아 보세요. 그래도 같다면 응용 프로그램 → 유틸리티 → 터미널을 열고 아래 한 줄을 붙여 넣은 뒤 return을 누르고, 다시 실행하세요.

xattr -dr com.apple.quarantine /Applications/SophiCut.app

완성본(영상 파일)은 어디에 저장되나요?

완성본이 나오면 「저장하기」로 원하는 곳에 받거나, 「폴더 열기」로 저장된 폴더를 바로 열 수 있습니다.

백신 프로그램이 설치 파일을 막아요

새로 나온 프로그램이라 일부 백신이 조심스럽게 막는 경우가 있습니다. 이 사이트나 공식 GitHub에서 받은 파일이 맞다면 백신의 「허용」 또는 「예외」에 추가해 주세요.

내 영상이 인터넷으로 전송되나요?

아니요. 받아쓰기를 포함한 모든 작업이 내 컴퓨터 안에서만 이루어집니다.

지우고 싶어요

Windows: 설정 → 앱 → 설치된 앱에서 소피컷을 제거하세요. 프로젝트까지 지우려면 파일 탐색기 주소창에 %LOCALAPPDATA%\SophiCut을 입력해 열린 폴더를 지웁니다.

Mac: 응용 프로그램 폴더의 SophiCut을 휴지통으로 옮기세요. 프로젝트까지 지우려면 Finder에서 ⌘+shift+G를 누르고 ~/Library/Application Support/SophiCut을 열어 지웁니다.
